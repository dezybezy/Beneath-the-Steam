# 🎮 [Beneath the Steam]
[![Godot Version](https://img.shields.io/badge/Godot-4.x-blue?logo=godot-
engine&logoColor=white)](https://godotengine.org)
[![Platform](https://img.shields.io/badge/Platform-PC%20/%20Web-green)](https://
godotengine.org)
A cafe simulator shrouded in fog and mysteries of the yokai in which the player must work while learning about the town's past.
---
## 🎮 How to Play
Provide clear, immediate instructions on how to run and control the game.
### **Installation / Execution**
* **Web Build:** [https://dezybezy.itch.io/beneath-the-steam]

### **Controls**
* `Arrow Keys`: Move character
* `Spacebar`: Interact w/customers
* `Left Click`: Interact w/buttons

## 🎮 Production Team & System Ownership
### **🎮 [Destiny Abreu] — Integration Lead/World Lead/Quest Lead**
* **System Ownership:** Core Mechanics, Physics Architecture, Input Locomotion, Ai Entities, Level Layout, & Interface Flows
* **Key Deliverables:**
* `player.gd`: Handles 8-way movement vectors, velocity damping, and screen
clamping.
* `game_manager.gd`: Coordinates global win/loss checks, score increments,
and scene reloads.
* `npc.gd` : Implements AI onto an NPC customer for the player to interact with
### **🎮 [Ameiko Samuel] — Avatar Lead**

* **Key Deliverables:**
